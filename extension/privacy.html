Privacy policy

Effective September 18, 2026.

GChat Translator reads Google Chat message text to add translation buttons. When you click Translate, Chrome's built-in Language Detector and Translator APIs process the selected message on your device.

The extension does not send messages or translations to the developer, a server, or a third-party translation service. It has no analytics, telemetry, advertising, accounts, or remote code.

Chrome may contact Google to download language models, which requires an internet connection. Once the models are available, translation runs locally. Chrome and Google Chat have their own privacy policies. This extension does not change how Google Chat stores or delivers conversations.

For embedded Chat, the extension passes the selected message between its scripts in the same browser tab. The message stays inside Chrome.

The extension saves your enabled setting and language choices in chrome.storage.local. It saves the settings panel theme in its localStorage. These settings contain no message text, translations, conversation IDs, or browsing history. The extension does not sync them.

Translations stay in page memory and on the page until the message disappears, settings change, or the page closes or reloads. Scripts with access to the page can read inline results. Turning off translation buttons removes results from open Chat pages.

The storage permission lets the extension save settings. Content scripts run on chat.google.com and mail.google.com/mail/ to add controls to Chat and support Gmail's embedded Chat. They do not target email messages. The extension does not request tabs, cookies, history, webRequest, or all-sites permission.

Uninstalling the extension removes its settings. Report privacy issues through the source repository's security reporting channel. Keep private conversations out of public reports.
